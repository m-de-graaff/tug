# DR-000: Template

**Status:** template
**Date:** —
**Phase:** —

## Context

What forced a decision. The constraint, the budget, the thing that broke, or the
fork in the road. Written so someone who joins in a year understands the pressure
without having been here.

## Options

Each real candidate, with what it costs. An option list where one entry is
obviously correct means the decision was already made and this record is
theatre — either find the real tension or don't write the record.

## Decision

What was chosen, in one sentence. Then the reasoning, including the number that
settled it where a number settled it.

## Consequences

What this makes easy, what it makes hard, and what it forecloses. Name the thing
that would make this decision wrong, so the revisit has a trigger rather than a
vague sense that it might be time.
