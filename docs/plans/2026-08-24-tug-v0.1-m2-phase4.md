# tug v0.1 «Hull» — Phase 4 «Renderer» Implementation Plan

> **To execute:** use the `executing-plans` skill. Steps use `- [ ]` for tracking.

**Goal:** Ship Phase 4 of `.artifacts/v0.0.md` — streaming markdown into normal
scrollback, flicker-free, with exact physical-row accounting — as a pure function
from an event script to ANSI bytes, and wire it into the binary behind a debug
flag so the eyeball test can be run.

**Architecture:** The renderer owns two regions. **Committed scrollback** is
printed once and never touched again; the terminal owns it from then on.
The **active tail** is a bounded set of logical lines that gets erased and
repainted every frame. A frame is: move the cursor back over the previous
tail, erase to end of display, print any lines that have aged out of the tail
(they become scrollback), print the tail, print the status hint, end on a fresh
row. The number of rows to move back is counted by the same code that emits
them, which is what makes the count exact rather than hopeful.

Three layers, each pure and separately testable:

1. `width.zig` — a codepoint is 0, 1, or 2 cells wide (`DR-005`).
2. `markdown.zig` — a raw line becomes a classified logical line; a logical
   line becomes a sequence of styled pieces.
3. `renderer.zig` — pieces become physical rows at a given width, and rows
   become bytes, through one writer, once per frame.

**Tech stack:** Zig 0.16.0, pinned via `minimum_zig_version` in `build.zig.zon`.
No third-party dependencies. `std.Io.Writer` for output, `std.ArrayList` (which
is unmanaged in 0.16 — every mutating method takes the allocator) for the tail.

### Zig 0.16 API notes

Facts established by reading the pinned standard library, so no task has to
guess:

- `std.ArrayList(T)` **is** `ArrayListUnmanaged`. Init with `.empty`; every
  mutating method takes the allocator first: `append(gpa, item)`,
  `appendSlice(gpa, items)`, `deinit(gpa)`. Shrinking needs no allocator —
  assigning `list.items.len = n` is what `shrinkRetainingCapacity` does.
- `std.Io.Writer` is `{ vtable: *const VTable, buffer: []u8, end: usize }`.
  `VTable.drain` is the only required field; `sendFile`, `flush` and `rebase`
  have defaults. A custom writer is a struct with a `writer: std.Io.Writer`
  field, recovered inside `drain` with
  `@alignCast(@fieldParentPtr("writer", w))` — `std.Io.Writer.Discarding` is
  the model to copy.
- `std.Io.Writer.fixed(&buf)` returns a writer that fails with
  `error.WriteFailed` when the buffer fills, and `buffered()` returns what is
  in it. This is what the golden tests capture into.
- `std.unicode` has `utf8ByteSequenceLength(first_byte) !u3`,
  `utf8Decode(bytes) !u21`, and `replacement_character` (`0xFFFD`).
- `std.mem.indexOfPos(u8, haystack, start, needle) ?usize` is the scan the
  inline parser uses to find a closing marker.

### Terminal facts this phase depends on

- **`CSI n F`** (CPL, cursor previous line) moves the cursor up `n` rows *and*
  to column 0. `n = 0` is treated as 1 by most terminals, so it is never
  emitted with a zero argument.
- **`CSI 0 J`** (ED 0) erases from the cursor to the end of the display.
- Every row this renderer emits ends with `\r\n`, never a bare `\n`. A row that
  is exactly `cols` cells wide leaves the terminal in the pending-wrap state;
  `\r` resolves it to column 0 of the same row and `\n` then moves down
  exactly one. A bare `\n` from the pending-wrap state moves down two on some
  terminals, and that is precisely the off-by-one that eats scrollback.
- **`CSI ? 2026 h` / `l`** wrap a frame as one atomic update where the terminal
  supports it (`DR-004`). Support is already detected and sits in
  `Capabilities.synchronized_output`.

fn inTable(table: []const [2]u21, cp: u21) bool {
    var low: usize = 0;
    var high: usize = table.len;
    while (low < high) {
        const mid = low + (high - low) / 2;
        if (cp < table[mid][0]) {
            high = mid;
        } else if (cp > table[mid][1]) {
            low = mid + 1;
        } else {
            return true;
        }
    }
    return false;
}

pub fn codepointWidth(cp: u21) u2 {
    // C0, DEL and C1. A terminal draws none of these, and the renderer never
    // emits them, but a text delta can carry one and the wrap arithmetic has to
    // agree with what lands on screen.
    if (cp < 0x20) return 0;
    if (cp >= 0x7f and cp < 0xa0) return 0;

    // The overwhelmingly common case, answered before either table is touched.
    if (cp < 0x0300) return 1;

    if (inTable(&zero_width, cp)) return 0;
    if (inTable(&wide, cp)) return 2;
    return 1;
}

pub fn stringWidth(text: []const u8) usize {
    var total: usize = 0;
    var index: usize = 0;
    while (index < text.len) {
        const length = std.unicode.utf8ByteSequenceLength(text[index]) catch {
            // An invalid lead byte renders as one replacement character. Advance
            // by one so a malformed stream can never stall this loop.
            total += 1;
            index += 1;
            continue;
        };
        if (index + length > text.len) {
            total += 1;
            break;
        }
        const cp = std.unicode.utf8Decode(text[index..][0..length]) catch {
            total += 1;
            index += 1;
            continue;
        };
        total += codepointWidth(cp);
        index += length;
    }
    return total;
}

- **Status:** accepted. **Date:** 2026-08-24. **Phase:** 4.
- **Context.** The renderer wraps text itself so it knows the tail's physical
  row count exactly; if the width function disagrees with the terminal by one
  cell, the cursor-up count is wrong and the repaint eats a row of scrollback.
  Width is therefore not a cosmetic concern, it is the correctness input to the
  one arithmetic that must never be wrong.
- **Options.** (a) Byte length — wrong for every non-ASCII user, free.
  (b) Codepoint-level `wcwidth`-style tables — a few hundred bytes of rodata,
  right for CJK and combining marks, wrong for ZWJ emoji sequences.
  (c) Grapheme-cluster segmentation via a vendored `zg` — correct for emoji,
  costs a dependency and a table an order of magnitude larger, against a
  500 KiB budget on a release whose exit criteria never mention emoji.
- **Decision.** (b), with two deliberate coarsenings: the emoji blocks are
  treated as uniformly wide rather than enumerated codepoint by codepoint, and
  the zero-width table covers combining marks by block. Terminals themselves
  disagree about emoji width; matching any one of them exactly is not
  achievable, and the block approximation matches what the matrix terminals do.
- **Consequences.** A ZWJ sequence such as a family emoji measures as its parts
  and wraps early — visible as a short line, never as corrupted scrollback,
  because the renderer's own count stays self-consistent. The revisit trigger
  is the v0.9 Unicode certification, which vendors `zg` for grapheme-aware
  width; when it lands, `codepointWidth` becomes its fast path for ASCII and
  the tables go away.

```zig
//! Markdown-lite: enough of the syntax to read a model's answer, and no more.
//!
//! Two rules keep this small enough to trust. **Everything is line-local** —
//! there is no cross-line emphasis, so a stray `*` can never style the rest of
//! a response, and a line can be classified the moment it terminates.
//! **Unmatched markers are text** — the parser never speculates about bytes it
//! has not seen, which is what makes it correct on a stream that stops
//! mid-line.
//!
//! What it deliberately does not do: nested lists (a marker must start at
//! column 0), setext headings, block quotes, tables, links, images, HTML,
//! backslash escapes, and syntax highlighting inside fences. Each is either a
//! later phase or a scope guard, not an oversight.

const std = @import("std");

/// Styling is attributes only — bold, dim, italic. No colour anywhere in
/// Phase 4: colour is a theme slot, themes are Phase 9, and a renderer that
/// hardcodes colours now is a renderer Phase 9 has to unpick.
pub const Style = packed struct(u8) {
    bold: bool = false,
    dim: bool = false,
    italic: bool = false,
    _padding: u5 = 0,
};

pub const LineKind = enum { blank, paragraph, heading, bullet, ordered, code };

pub const Line = struct {
    kind: LineKind,
    level: u8 = 0,
    start: u32,
    len: u32,
};

pub const Classified = struct {
    kind: LineKind,
    level: u8 = 0,
    marker_len: u32 = 0,
};

pub fn isFence(text: []const u8) bool {
    return std.mem.startsWith(u8, text, "```");
}

pub fn classify(text: []const u8, in_fence: bool) Classified {
    // Inside a fence the bytes are the user's, verbatim. A `#` there is a
    // comment in half the languages a model writes.
    if (in_fence) return .{ .kind = .code };

    if (std.mem.trim(u8, text, " \t").len == 0) return .{ .kind = .blank };

    if (text[0] == '#') {
        var hashes: u8 = 0;
        while (hashes < text.len and text[hashes] == '#') hashes += 1;
        if (hashes <= 6 and hashes < text.len and text[hashes] == ' ') {
            return .{ .kind = .heading, .level = hashes, .marker_len = hashes + 1 };
        }
        return .{ .kind = .paragraph };
    }

    if (text.len >= 2 and (text[0] == '-' or text[0] == '*' or text[0] == '+') and text[1] == ' ') {
        return .{ .kind = .bullet, .marker_len = 2 };
    }

    var digits: usize = 0;
    while (digits < text.len and std.ascii.isDigit(text[digits])) digits += 1;
    if (digits > 0 and digits + 1 < text.len and text[digits] == '.' and text[digits + 1] == ' ') {
        // A list numbered past 255 is not a list anyone is reading; saturating
        // keeps `level` a byte and the render prefix short.
        const number = std.fmt.parseInt(u8, text[0..digits], 10) catch 255;
        return .{ .kind = .ordered, .level = number, .marker_len = @intCast(digits + 2) };
    }

    return .{ .kind = .paragraph };
}

pub const Piece = struct { bytes: []const u8, style: Style };

pub const Inline = struct {
    text: []const u8,
    base: Style,
    index: usize = 0,

    pub fn init(text: []const u8, base: Style) Inline {
        return .{ .text = text, .base = base };
    }

    /// The marker at `index`, and where its content ends, or null when the
    /// marker is unmatched on this line and is therefore just text.
    const Match = struct { marker: usize, content_end: usize, style: Style };

    fn matchAt(self: *const Inline, index: usize) ?Match {
        const rest = self.text[index..];
        if (std.mem.startsWith(u8, rest, "`")) {
            const close = std.mem.indexOfPos(u8, self.text, index + 1, "`") orelse return null;
            return .{ .marker = 1, .content_end = close, .style = .{ .dim = true } };
        }
        if (std.mem.startsWith(u8, rest, "**")) {
            const close = std.mem.indexOfPos(u8, self.text, index + 2, "**") orelse return null;
            return .{ .marker = 2, .content_end = close, .style = .{ .bold = true } };
        }
        if (std.mem.startsWith(u8, rest, "*")) {
            const close = std.mem.indexOfPos(u8, self.text, index + 1, "*") orelse return null;
            return .{ .marker = 1, .content_end = close, .style = .{ .italic = true } };
        }
        return null;
    }

    fn merge(base: Style, overlay: Style) Style {
        return .{
            .bold = base.bold or overlay.bold,
            .dim = base.dim or overlay.dim,
            .italic = base.italic or overlay.italic,
        };
    }

    pub fn next(self: *Inline) ?Piece {
        while (self.index < self.text.len) {
            if (self.matchAt(self.index)) |match| {
                const content_start = self.index + match.marker;
                self.index = match.content_end + match.marker;
                // `****` and `` `` `` are markers around nothing. Skipping them
                // rather than emitting an empty piece keeps every consumer free
                // of a zero-length special case.
                if (content_start == match.content_end) continue;
                return .{
                    .bytes = self.text[content_start..match.content_end],
                    .style = merge(self.base, match.style),
                };
            }

            // Plain text runs until the next marker that actually matches.
            // Scanning for matches rather than for marker bytes is what makes
            // an unmatched `**` part of the text instead of a style change.
            //
            // ponytail: this rescans from each position, so a line of nothing
            // but unmatched markers is quadratic in its length. Lines are one
            // screen wide in practice; if a pathological line ever shows up in
            // a profile, remember the failed scan instead.
            var scan = self.index + 1;
            while (scan < self.text.len) : (scan += 1) {
                if (self.matchAt(scan) != null) break;
            }
            const piece = self.text[self.index..scan];
            self.index = scan;
            return .{ .bytes = piece, .style = self.base };
        }
        return null;
    }
};

```zig
//! A writer that counts how often bytes actually reach the sink.
//!
//! This exists for one invariant: **one `write()` per frame.** A frame that
//! reaches the terminal in two syscalls can be observed half-drawn, and the
//! flicker-free claim is not about the terminal's synchronized-output support
//! — that is an optimization on top. Composing the whole frame and flushing it
//! once is the guarantee, so the test needs to see the syscalls.
//!
//! Test-only: nothing outside a test block imports this.

const std = @import("std");

pub const Counting = struct {
    writer: std.Io.Writer,
    sink: []u8,
    len: usize = 0,
    writes: usize = 0,

    pub fn init(buffer: []u8, sink: []u8) Counting {
        return .{
            .writer = .{ .vtable = &vtable, .buffer = buffer },
            .sink = sink,
        };
    }

    const vtable: std.Io.Writer.VTable = .{ .drain = drain };

    fn drain(w: *std.Io.Writer, data: []const []const u8, splat: usize) std.Io.Writer.Error!usize {
        const self: *Counting = @alignCast(@fieldParentPtr("writer", w));
        self.writes += 1;

        // Buffered bytes are logically written first, then each slice of
        // `data`, with the last repeated `splat` times.
        self.append(w.buffer[0..w.end]) catch return error.WriteFailed;
        w.end = 0;

        var consumed: usize = 0;
        for (data[0 .. data.len - 1]) |slice| {
            self.append(slice) catch return error.WriteFailed;
            consumed += slice.len;
        }
        const pattern = data[data.len - 1];
        for (0..splat) |_| {
            self.append(pattern) catch return error.WriteFailed;
            consumed += pattern.len;
        }
        return consumed;
    }

    fn append(self: *Counting, slice: []const u8) error{Overflow}!void {
        if (self.len + slice.len > self.sink.len) return error.Overflow;
        @memcpy(self.sink[self.len..][0..slice.len], slice);
        self.len += slice.len;
    }

    /// Everything written so far, including whatever is still buffered.
    pub fn bytes(self: *const Counting) []const u8 {
        return self.sink[0..self.len];
    }
};

//! Streaming into normal scrollback, without ever rewriting it.
//!
//! The screen has two regions and they never mix. **Committed scrollback** has
//! been printed and belongs to the terminal from that moment on — tug will not
//! move the cursor over it again, which is why resizing it is the terminal's
//! problem and why a crash cannot corrupt it. The **active tail** is the last
//! few rows: erased and repainted on every frame, and bounded to fit on screen
//! so the cursor-up that starts a repaint can always reach its top row.
//!
//! A frame is one buffer and one flush:
//!
//!   [ ?2026h ] \r  CPL(tail_rows)  ED(0)  <aged-out rows>  <tail rows>  [ ?2026l ]
//!
//! and it always ends having emitted `\r\n` after its last row, so the cursor
//! parks at column 0 of a fresh row below the tail. That is the invariant every
//! piece of arithmetic here rests on: `tail_rows` is the number of rows
//! *above* the cursor that belong to the tail, and the next frame moves up
//! exactly that many.
//!
//! Rows are counted by the same function that emits them, called once with a
//! null writer to measure and once with the real one to draw. Two functions
//! would drift, and drift here means eating a row of the user's scrollback.

const std = @import("std");

const backend = @import("../term/backend.zig");
const caps_mod = @import("../term/caps.zig");
const md = @import("markdown.zig");
const width_mod = @import("width.zig");

pub const Size = backend.Size;
pub const Capabilities = caps_mod.Capabilities;

pub const BlockKind = enum { user, assistant, notice };

pub const Frame = struct { committed_rows: u32 = 0, tail_rows: u32 = 0 };

/// The status hint, shown while a block is open and gone the moment it commits
/// (`DR-008`). One dim row, ASCII on purpose: a status line is the last place
/// to discover that a terminal disagrees about a glyph's width.
const status_hint = "... streaming";

/// Style transitions are emitted as a full reset followed by the new
/// attributes. SGR 22 turns off bold *and* dim together, so tracking them
/// incrementally means tracking which of the two `22` was meant to clear. A
/// reset costs three bytes and removes the question.
fn writeStyle(out: *std.Io.Writer, style: md.Style) std.Io.Writer.Error!void {
    try out.writeAll("\x1b[0m");
    if (style.bold) try out.writeAll("\x1b[1m");
    if (style.dim) try out.writeAll("\x1b[2m");
    if (style.italic) try out.writeAll("\x1b[3m");
}

/// The longest complete UTF-8 prefix of `bytes`.
///
/// The tail's incomplete trailing line can end mid-codepoint, and painting half
/// a codepoint puts a replacement character on screen that vanishes on the next
/// frame. Holding the fragment back is one comparison and one frame of latency.
fn completePrefix(bytes: []const u8) usize {
    var index = bytes.len;
    var back: usize = 0;
    while (index > 0 and back < 4) : (back += 1) {
        index -= 1;
        const length = std.unicode.utf8ByteSequenceLength(bytes[index]) catch continue;
        // A lead byte whose sequence is complete leaves the whole slice intact.
        if (index + length <= bytes.len) return bytes.len;
        return index;
    }
    return bytes.len;
}

pub const Renderer = struct {
    caps: Capabilities,
    size: Size,

    /// Every logical line's bytes, back to back. Line ranges index into this.
    text: std.ArrayList(u8) = .empty,
    lines: std.ArrayList(md.Line) = .empty,
    /// Bytes of the incomplete trailing line, which has no `Line` entry yet.
    partial: std.ArrayList(u8) = .empty,

    block: ?BlockKind = null,
    in_fence: bool = false,
    /// Set by `endBlock`; the next paint commits the whole block and clears it.
    closing: bool = false,

    tail_rows: u32 = 0,
    painted: bool = false,

    pub fn init(caps: Capabilities, size: Size) Renderer {
        return .{ .caps = caps, .size = size };
    }

    pub fn deinit(self: *Renderer, gpa: std.mem.Allocator) void {
        self.text.deinit(gpa);
        self.lines.deinit(gpa);
        self.partial.deinit(gpa);
        self.* = undefined;
    }

    /// A resize invalidates nothing but the wrap: logical lines are stored
    /// unwrapped precisely so this is a field assignment. `tail_rows` is a
    /// count at the *old* width and is deliberately left alone — the terminals
    /// in the v0.1 matrix reflow their own scrollback on resize, so the rows
    /// the next paint moves back over are the reflowed ones, and re-deriving
    /// the count here would assume a reflow policy tug cannot observe.
    pub fn setSize(self: *Renderer, size: Size) void {
        self.size = size;
    }

    pub fn beginBlock(self: *Renderer, gpa: std.mem.Allocator, kind: BlockKind) !void {
        if (self.block != null) try self.endBlock(gpa);
        self.block = kind;
        self.in_fence = false;
        self.closing = false;
    }

    pub fn feed(self: *Renderer, gpa: std.mem.Allocator, bytes: []const u8) !void {
        var rest = bytes;
        while (std.mem.indexOfScalar(u8, rest, '\n')) |newline| {
            try self.partial.appendSlice(gpa, rest[0..newline]);
            try self.finishLine(gpa);
            rest = rest[newline + 1 ..];
        }
        try self.partial.appendSlice(gpa, rest);
    }

    /// Turns the accumulated partial into a classified logical line.
    fn finishLine(self: *Renderer, gpa: std.mem.Allocator) !void {
        // Carriage returns arrive from providers that think they are writing to
        // a terminal. They are not markup and they would wreck the cursor
        // arithmetic, so they are dropped rather than passed through.
        const raw = std.mem.trimEnd(u8, self.partial.items, "\r");

        if (self.plainBlock()) {
            try self.appendLine(gpa, .{ .kind = .paragraph }, raw);
        } else if (md.isFence(raw)) {
            // The marker itself is never echoed; it only toggles the state.
            self.in_fence = !self.in_fence;
        } else {
            try self.appendLine(gpa, md.classify(raw, self.in_fence), raw);
        }
        self.partial.clearRetainingCapacity();
    }

    fn appendLine(
        self: *Renderer,
        gpa: std.mem.Allocator,
        classified: md.Classified,
        raw: []const u8,
    ) !void {
        const content = raw[@min(classified.marker_len, raw.len)..];
        const start: u32 = @intCast(self.text.items.len);
        try self.text.appendSlice(gpa, content);
        try self.lines.append(gpa, .{
            .kind = classified.kind,
            .level = classified.level,
            .start = start,
            .len = @intCast(content.len),
        });
    }

    /// User and notice blocks are text, not markdown. A user's own words are
    /// echoed as typed, and a notice is one sentence from tug itself.
    fn plainBlock(self: *const Renderer) bool {
        return self.block != .assistant;
    }

    pub fn endBlock(self: *Renderer, gpa: std.mem.Allocator) !void {
        if (self.block == null) return;
        if (self.partial.items.len > 0) try self.finishLine(gpa);
        self.closing = true;
    }

    /// The style every line of the current block inherits.
    fn baseStyle(self: *const Renderer, line: md.Line) md.Style {
        var style: md.Style = .{};
        switch (self.block orelse .assistant) {
            .assistant => {},
            .user => style.bold = true,
            .notice => style.dim = true,
        }
        switch (line.kind) {
            .heading => style.bold = true,
            .code => style.dim = true,
            else => {},
        }
        return style;
    }

    fn prefix(line: md.Line, buffer: []u8) []const u8 {
        return switch (line.kind) {
            .bullet => "\u{2022} ",
            .ordered => std.fmt.bufPrint(buffer, "{d}. ", .{line.level}) catch "- ",
            else => "",
        };
    }

    pub fn paint(self: *Renderer, out: *std.Io.Writer) std.Io.Writer.Error!Frame {
        // One row is held back so the status hint always has somewhere to go and
        // the cursor's parking row is never the top of the screen.
        const capacity: u32 = @max(1, @as(u32, self.size.rows) -| 2);

        var rows_of_line: [64]u32 = undefined;
        var total: u32 = 0;
        for (self.lines.items, 0..) |line, i| {
            const rows = self.renderLine(line, null) catch unreachable;
            if (i < rows_of_line.len) rows_of_line[i] = rows;
            total += rows;
        }
        const partial_rows = try self.renderPartial(null);
        total += partial_rows;
        if (!self.closing and self.block != null) total += 1; // status hint

        // Age lines out of the tail from the top until what is left fits on
        // screen. A closing block ages out entirely: that is the commit rule.
        var commit_count: usize = 0;
        if (self.closing) {
            commit_count = self.lines.items.len;
        } else {
            while (total > capacity and commit_count < self.lines.items.len) {
                const rows = if (commit_count < rows_of_line.len)
                    rows_of_line[commit_count]
                else
                    self.renderLine(self.lines.items[commit_count], null) catch unreachable;
                total -= rows;
                commit_count += 1;
            }
        }

        if (self.caps.synchronized_output) try out.writeAll("\x1b[?2026h");

        if (self.painted) {
            try out.writeAll("\r");
            if (self.tail_rows > 0) try out.print("\x1b[{d}F", .{self.tail_rows});
            try out.writeAll("\x1b[0J");
        }

        var frame: Frame = .{};
        for (self.lines.items[0..commit_count]) |line| {
            frame.committed_rows += try self.renderLine(line, out);
            try out.writeAll("\r\n");
        }
        for (self.lines.items[commit_count..]) |line| {
            frame.tail_rows += try self.renderLine(line, out);
            try out.writeAll("\r\n");
        }
        frame.tail_rows += try self.renderPartial(out);
        if (!self.closing and self.block != null) {
            try writeStyle(out, .{ .dim = true });
            try out.writeAll(status_hint);
            try writeStyle(out, .{});
            try out.writeAll("\r\n");
            frame.tail_rows += 1;
        }

        if (self.caps.synchronized_output) try out.writeAll("\x1b[?2026l");

        self.dropCommitted(commit_count);
        if (self.closing) {
            self.block = null;
            self.closing = false;
            self.in_fence = false;
        }
        self.tail_rows = frame.tail_rows;
        self.painted = true;
        return frame;
    }

    /// The incomplete trailing line, rendered as a paragraph and truncated to
    /// its last whole codepoint. Emits no `\r\n` of its own when it is empty,
    /// so an idle renderer paints nothing.
    fn renderPartial(self: *Renderer, out: ?*std.Io.Writer) std.Io.Writer.Error!u32 {
        const usable = self.partial.items[0..completePrefix(self.partial.items)];
        if (usable.len == 0) return 0;
        const style: md.Style = if (self.in_fence) .{ .dim = true } else .{};
        const rows = try self.wrap(usable, style, "", self.plainBlock() or self.in_fence, out);
        if (out) |writer| try writer.writeAll("\r\n");
        return rows;
    }

    fn renderLine(self: *Renderer, line: md.Line, out: ?*std.Io.Writer) std.Io.Writer.Error!u32 {
        var prefix_buffer: [8]u8 = undefined;
        const marker = prefix(line, &prefix_buffer);
        const content = self.text.items[line.start..][0..line.len];
        const literal = self.plainBlock() or line.kind == .code;
        return self.wrap(content, self.baseStyle(line), marker, literal, out);
    }

    /// Emits one logical line as physical rows and returns how many. With a null
    /// writer it does the identical walk and emits nothing, which is what makes
    /// the count and the output impossible to disagree.
    ///
    /// Rows break at the last space that fits; a word too long for a whole row
    /// is broken where it lands, because the alternative is a row of nothing.
    /// Continuation rows are indented under the marker, so a wrapped list item
    /// still reads as one item.
    fn wrap(
        self: *Renderer,
        content: []const u8,
        base: md.Style,
        marker: []const u8,
        literal: bool,
        out: ?*std.Io.Writer,
    ) std.Io.Writer.Error!u32 {
        const cols: usize = @max(1, self.size.cols);
        const indent = width_mod.stringWidth(marker);
        const hanging = if (indent < cols) indent else 0;

        var rows: u32 = 1;
        var column: usize = 0;
        var style: md.Style = base;

        if (out) |writer| {
            try writeStyle(writer, base);
            try writer.writeAll(marker);
        }
        column += indent;

        // A break opportunity: where the last space was, and what the style was
        // there, so the continuation row can re-open it.
        var break_pending = false;

        var pieces: md.Inline = .init(content, base);
        var plain: md.Piece = .{ .bytes = content, .style = base };
        var plain_done = false;

        while (true) {
            const piece = if (literal) blk: {
                if (plain_done) break;
                plain_done = true;
                break :blk plain;
            } else pieces.next() orelse break;

            if (out) |writer| {
                if (@as(u8, @bitCast(piece.style)) != @as(u8, @bitCast(style))) {
                    try writeStyle(writer, piece.style);
                }
            }
            style = piece.style;

            var index: usize = 0;
            while (index < piece.bytes.len) {
                const length = std.unicode.utf8ByteSequenceLength(piece.bytes[index]) catch 1;
                const end = @min(index + length, piece.bytes.len);
                const slice = piece.bytes[index..end];
                const cell = width_mod.stringWidth(slice);

                if (column + cell > cols) {
                    if (out) |writer| {
                        try writeStyle(writer, .{});
                        try writer.writeAll("\r\n");
                        try writer.splatByteAll(' ', hanging);
                        try writeStyle(writer, style);
                    }
                    rows += 1;
                    column = hanging;
                }

                if (out) |writer| try writer.writeAll(slice);
                column += cell;
                index = end;
                break_pending = slice.len == 1 and slice[0] == ' ';
            }
        }
        _ = &break_pending;

        if (out) |writer| try writeStyle(writer, .{});
        return rows;
    }

    /// Removes the lines that have gone into scrollback and compacts the text
    /// behind them.
    ///
    /// ponytail: this memmoves the surviving bytes to the front, so a commit is
    /// linear in the tail's size. The tail is one screenful by construction, so
    /// that is a few kilobytes at 125 frames a second. A ring buffer would
    /// avoid it and cost every reader a wrap-around branch.
    fn dropCommitted(self: *Renderer, count: usize) void {
        if (count == 0) return;
        if (count >= self.lines.items.len) {
            self.lines.clearRetainingCapacity();
            self.text.clearRetainingCapacity();
            return;
        }
        const cut = self.lines.items[count].start;
        std.mem.copyForwards(u8, self.text.items, self.text.items[cut..]);
        self.text.items.len -= cut;
        std.mem.copyForwards(md.Line, self.lines.items, self.lines.items[count..]);
        self.lines.items.len -= count;
        for (self.lines.items) |*line| line.start -= cut;
    }
};

Note on `opening a block while one is open closes the first`: `beginBlock`
calls `endBlock`, which only sets `closing`. Two blocks cannot both commit in
one paint with a single `closing` flag, so this test forces the fix — `closing`
becomes a count of lines to commit rather than a bool:

```zig
    /// Lines from the front that belong to blocks already closed. They commit
    /// on the next paint no matter how much room is left.
    closed_lines: usize = 0,
```

`endBlock` sets `self.closed_lines = self.lines.items.len;` and clears
`self.block`. `paint` starts `commit_count` at `self.closed_lines`, then ages
further lines out if the remainder still does not fit, and afterwards sets
`self.closed_lines = 0`. The status hint shows when `self.block != null`. Drop
the `closing` field.

`baseStyle` then needs the block a line belonged to, not the current one. Store
it on the line: add `block: BlockKind` to a wrapper the renderer keeps beside
`md.Line`, or — simpler and what to do — widen the renderer's line record:

```zig
const Entry = struct { line: md.Line, block: BlockKind };

and change `lines` to `std.ArrayList(Entry)`.

- [ ] **Step 5: Write DR-008**

Create `docs/decisions/DR-008-status-hint.md`, in the template's shape:

- **Status:** accepted. **Date:** 2026-08-24. **Phase:** 4.
- **Context.** While a response streams there is no other signal that tug is
  alive. A model that thinks for eight seconds before its first token is
  indistinguishable from a hung process, and the only place to say otherwise is
  the tail — which is the one region that can be erased without touching
  scrollback.
- **Options.** (a) Nothing: honest, and wrong the first time a provider stalls.
  (b) A spinner: needs a timer, and a timer means waking the loop on a schedule,
  which is the 0 % idle CPU budget spent on decoration. (c) One dim line in the
  tail, repainted with the frame it already repaints, gone when the block
  commits.
- **Decision.** (c). It costs one row of the tail budget, no timer, no extra
  wakeups, and it disappears through the same erase that repaints everything
  else. The text is ASCII on purpose: a status line is the last place to
  discover a terminal disagreeing about a glyph's width.
- **Consequences.** The tail's usable height is `rows - 2` rather than
  `rows - 1`, which matters only on terminals under about six rows. The revisit
  trigger is v0.7: statusline segments arrive there, and this hint is either
  their first segment or it is deleted. It must not grow a second line, a
  colour, or a spinner before then — each of those is a statusline feature
  wearing a disguise.

//! Golden transcripts: an event script and a fixed width in, ANSI bytes out.
//!
//! The renderer is a pure function, so its whole observable behaviour is a byte
//! string — and a byte string is reviewable. Every golden is checked in, and a
//! diff to one is a diff a human has to look at and agree with. That is the
//! point: the failure mode this phase is guarding against is a repaint that
//! looks fine and is off by a row, which no assertion about row counts alone
//! would catch.
//!
//! **Regenerating one:** the test prints the actual transcript to stderr on a
//! mismatch, framed by `--- golden <name> ---` markers. Read it, satisfy
//! yourself the change is intended, and paste it into the file. There is
//! deliberately no `--update` flag: a golden that can be refreshed without
//! reading it is a golden that stops meaning anything.

const std = @import("std");
const testing = std.testing;

const Counting = @import("counting_writer.zig").Counting;
const renderer_mod = @import("renderer.zig");
const Renderer = renderer_mod.Renderer;

const plain_caps: renderer_mod.Capabilities = .{
    .color = .none,
    .kitty_keyboard = false,
    .synchronized_output = false,
    .bracketed_paste = true,
    .size = .{ .cols = 24, .rows = 8 },

fn escape(out: *std.Io.Writer, bytes: []const u8) !void {
    for (bytes) |byte| switch (byte) {
        0x1b => try out.writeAll("\\e"),
        '\r' => try out.writeAll("\\r"),
        '\n' => try out.writeAll("\n"),
        else => try out.writeByte(byte),
    };
}

fn check(name: []const u8, expected: []const u8, frames: []const []const u8) !void {
    var buffer: [64 * 1024]u8 = undefined;
    var writer: std.Io.Writer = .fixed(&buffer);
    for (frames) |frame| try escape(&writer, frame);
    const actual = writer.buffered();

    if (std.mem.eql(u8, std.mem.trimEnd(u8, expected, "\n"), std.mem.trimEnd(u8, actual, "\n"))) return;

    std.debug.print(
        "\n--- golden {s} ---\n{s}\n--- end golden {s} ---\n",
        .{ name, actual, name },
    );
    return error.GoldenMismatch;
}

/// Drives a renderer through a script and returns each frame's bytes. Frames
/// are appended to `store`, which the caller owns.
fn run(
    gpa: std.mem.Allocator,
    caps: renderer_mod.Capabilities,
    script: []const Step,
    store: *std.ArrayList(u8),
    frames: *std.ArrayList([]const u8),
) !void {
    var renderer: Renderer = .init(gpa, caps, caps.size);
    defer renderer.deinit();

    for (script) |step| switch (step) {
        .begin => |kind| try renderer.beginBlock(kind),
        .feed => |bytes| try renderer.feed(bytes),
        .end => try renderer.endBlock(),
        .resize => |size| renderer.setSize(size),
        .paint => {
            var buffer: [16 * 1024]u8 = undefined;
            var sink: [16 * 1024]u8 = undefined;
            var counting: Counting = .init(&buffer, &sink);
            _ = try renderer.paint(&counting.writer);
            try counting.writer.flush();
            try testing.expectEqual(@as(usize, 1), counting.writes);
            const start = store.items.len;
            try store.appendSlice(gpa, counting.bytes());
            try frames.append(gpa, store.items[start..]);
        },
    };
}

const Step = union(enum) {
    begin: renderer_mod.BlockKind,
    feed: []const u8,
    end,
    resize: renderer_mod.Size,
    paint,
};

fn golden(name: []const u8, caps: renderer_mod.Capabilities, script: []const Step, expected: []const u8) !void {
    const gpa = testing.allocator;
    var store: std.ArrayList(u8) = .empty;
    defer store.deinit(gpa);
    var frames: std.ArrayList([]const u8) = .empty;
    defer frames.deinit(gpa);

    // Reserved up front: `store` must not reallocate, because `frames` holds
    // slices into it.
    try store.ensureTotalCapacity(gpa, 256 * 1024);

    try run(gpa, caps, script, &store, &frames);
    try check(name, expected, frames.items);
}

```zig
//! The one invariant that cannot be allowed to drift.
//!
//! Every frame ends with the cursor at column 0 of a fresh row, `tail_rows`
//! rows below the top of the tail. The next frame moves up exactly that many
//! and erases below. If the count is one too high the repaint eats a row of the
//! user's scrollback — permanently, because scrollback is the one thing tug
//! never rewrites. If it is one too low the old tail is left on screen under
//! the new one.
//!
//! So this checks two things over randomized content and widths: that the rows
//! a frame reports are the rows it actually emitted, and that the next frame's
//! CPL argument is the previous frame's tail count.

const std = @import("std");
const testing = std.testing;

const Counting = @import("counting_writer.zig").Counting;
const renderer_mod = @import("renderer.zig");
const Renderer = renderer_mod.Renderer;

const alphabet = [_][]const u8{
    "a",       "bb",       "ccc",  "dddd",  " ",        " ",  " ",
    "\n",      "\n",       "# ",   "- ",    "1. ",      "**", "`",
    "\u{65e5}", "\u{672c}", "\u{1f600}", "e\u{0301}", "```\n",
};

/// Counts physical rows in a frame the way a terminal would: one per `\r\n`
/// that is not part of an escape sequence. Every row this renderer emits ends
/// with `\r\n`, and no escape sequence it emits contains one.
fn countRows(frame: []const u8) u32 {
    var rows: u32 = 0;
    var index: usize = 0;
    while (std.mem.indexOfPos(u8, frame, index, "\r\n")) |at| {
        rows += 1;
        index = at + 2;
    }
    return rows;
}

/// The CPL argument at the start of a frame, or null when the frame has none.
fn cursorUp(frame: []const u8) ?u32 {
    if (!std.mem.startsWith(u8, frame, "\r\x1b[")) return null;
    const rest = frame["\r\x1b[".len..];
    const end = std.mem.indexOfScalar(u8, rest, 'F') orelse return null;
    return std.fmt.parseInt(u32, rest[0..end], 10) catch null;
}

test "reported rows are emitted rows, and the next frame moves back over exactly them" {
    const gpa = testing.allocator;
    var prng: std.Random.DefaultPrng = .init(0x7c9f_2b41);
    const random = prng.random();

    var buffer: [64 * 1024]u8 = undefined;
    var sink: [64 * 1024]u8 = undefined;

    for (0..400) |_| {
        const cols: u16 = random.intRangeAtMost(u16, 1, 60);
        const rows: u16 = random.intRangeAtMost(u16, 1, 24);
        const caps: renderer_mod.Capabilities = .{
            .color = .none,
            .kitty_keyboard = false,
            .synchronized_output = random.boolean(),
            .bracketed_paste = true,
            .size = .{ .cols = cols, .rows = rows },
        };

        var renderer: Renderer = .init(gpa, caps, caps.size);
        defer renderer.deinit();
        try renderer.beginBlock(.assistant);

        var previous_tail: ?u32 = null;
        const paints = random.intRangeAtMost(usize, 1, 6);
        for (0..paints) |_| {
            const chunks = random.intRangeAtMost(usize, 0, 12);
            for (0..chunks) |_| {
                try renderer.feed(alphabet[random.uintLessThan(usize, alphabet.len)]);
            }
            if (random.boolean()) {
                renderer.setSize(.{
                    .cols = random.intRangeAtMost(u16, 1, 60),
                    .rows = random.intRangeAtMost(u16, 1, 24),
                });
            }

            var counting: Counting = .init(&buffer, &sink);
            const frame = try renderer.paint(&counting.writer);
            try counting.writer.flush();
            const output = counting.bytes();

            // The frame reports what it emitted.
            try testing.expectEqual(
                frame.committed_rows + frame.tail_rows,
                countRows(output),
            );

            // The frame moved back over exactly the previous frame's tail.
            if (previous_tail) |expected| {
                if (expected == 0) {
                    try testing.expectEqual(@as(?u32, null), cursorUp(output));
                } else {
                    try testing.expectEqual(@as(?u32, expected), cursorUp(output));
                }
            }
            previous_tail = frame.tail_rows;

            // The tail always fits on screen, or the cursor-up cannot reach it.
            try testing.expect(frame.tail_rows <= renderer.size.rows);
        }
    }
}

Note: `cursorUp` reads the frame *after* any synchronized-output prefix, so
either strip `\x1b[?2026h` before calling it or start the search at the first

/// The burst the renderer is exercised against until Phase 5's mock provider
/// replaces it. Markdown-rich on purpose: headings, both list kinds, a fence,
/// inline markers, CJK and an emoji, so one run touches every width path.
const render_script =
    \\# Bollard pull
    \\
    \\A tugboat's power is rated in **bollard pull** — a tiny vessel, absurdly
    \\overpowered, guiding something a thousand times its mass. That is the
    \\product, and it is why the binary is measured in kilobytes.
    \\
    \\- One static binary, no runtime, no telemetry
    \\- A shell, a loop, two providers, four tools, a plugin socket
    \\- Everything else is a plugin
    \\
    \\1. Wrap to the terminal's width, and know the row count exactly
    \\2. Repaint the tail, never the scrollback
    \\3. One `write` per frame
    \\
    \\```zig
    \\pub fn main() !void {
    \\    // **not bold** inside a fence
    \\    std.debug.print("ship it\n", .{});
    \\}
    \\```
    \\
    \\日本語のテキストも折り返します。 🚢 And back to *ASCII* again, with a
    \\paragraph long enough to wrap more than once at any sensible width.
    \\
;

/// How many chunks are fed per frame. Eight at 125 frames a second is roughly a
/// thousand deltas a second, which is a firehose by any provider's standard and
/// is what the no-flicker eyeball test wants to see.
const render_chunks_per_frame = 8;
const render_chunk_bytes = 7;

const RenderDemo = struct {
    renderer: *shell.Renderer,
    scheduler: *core.Scheduler,
    terminal: *shell.Backend,
    out: *std.Io.Writer,
    offset: usize = 0,
    finished: bool = false,

    fn onInput(context: ?*anyopaque, event: shell.InputEvent) shell.loop.Flow {
        _ = context;
        return switch (event) {
            .key => |key_event| if (key_event.key == .char and key_event.mods.ctrl and
                key_event.codepoint == 'c') .stop else .keep_going,
            else => .keep_going,
        };
    }

    fn onRender(context: ?*anyopaque) anyerror!void {
        const self: *RenderDemo = @ptrCast(@alignCast(context.?));

        // The terminal is asked for its size every frame rather than tracked:
        // a resize wakes the loop, and one ioctl per frame is cheaper than the
        // bookkeeping that would avoid it.
        self.renderer.setSize(self.terminal.size());

        for (0..render_chunks_per_frame) |_| {
            if (self.offset >= render_script.len) break;
            const end = @min(self.offset + render_chunk_bytes, render_script.len);
            try self.renderer.feed(render_script[self.offset..end]);
            self.offset = end;
        }
        if (self.offset >= render_script.len and !self.finished) {
            try self.renderer.endBlock();
            self.finished = true;
        }

        _ = try self.renderer.paint(self.out);
        try self.out.flush();

        // More to say means another frame is owed; the scheduler decides when.
        if (!self.finished) self.scheduler.markDirty();
    }
};

fn debugRender(
    io: std.Io,
    stdout: *std.Io.Writer,
    environ: std.process.Environ,
    gpa: std.mem.Allocator,
) !void {
    var terminal = shell.backend.open() catch |err| switch (err) {
        error.NotATerminal => {
            try stdout.writeAll("not a terminal: nothing to render into\n");
            return stdout.flush();
        },
        else => return err,
    };
    try terminal.enterRaw();
    defer terminal.restore();

    const detected = shell.caps.detect(readEnv(environ, gpa), .{}, terminal.size());

    // The frame buffer is sized so a whole frame fits without an intermediate
    // flush. That sizing *is* the one-write-per-frame invariant on the real
    // terminal; the counting-writer test proves the renderer respects it.
    var frame_buffer: [256 * 1024]u8 = undefined;
    var terminal_writer = terminal.writer(io, &frame_buffer);
    const out = &terminal_writer.interface;

    var heap: std.heap.DebugAllocator(.{}) = .init;
    defer _ = heap.deinit();

    var renderer: shell.Renderer = .init(heap.allocator(), detected, terminal.size());
    defer renderer.deinit();
    try renderer.beginBlock(.assistant);

    var waker = try shell.Waker.open();
    defer waker.close();
    terminal.setWakeHandle(waker.writeHandle());

    var queue: shell.Queue = .{};
    var bus: core.Bus = .{};
    var scratch: [4096]u8 = undefined;
    var decoder: shell.Decoder = .{ .scratch = &scratch };
    var scheduler: core.Scheduler = .{};
    scheduler.markDirty();

    var demo: RenderDemo = .{
        .renderer = &renderer,
        .scheduler = &scheduler,
        .terminal = &terminal,
        .out = out,
    };

    var loop: shell.Loop = .{
        .io = io,
        .terminal = &terminal,
        .waker = &waker,
        .queue = &queue,
        .bus = &bus,
        .decoder = &decoder,
        .scheduler = &scheduler,
        .handlers = .{
            .context = &demo,
            .onInput = RenderDemo.onInput,
            .onRender = RenderDemo.onRender,
        },
    };
    try loop.run();
}
```

`shell.InputEvent`'s tags and `KeyEvent`'s fields come from `debugKeys` — copy

cannot see.

## Handoff

This plan is a hypothesis about work not yet done. Three places are most likely
to be wrong, and finding that out is part of executing it:

1. **`wrap`'s word buffering.** The sketch in Task 3 Step 5 changes the shape of
   the loop it replaces. Expect to restructure it; the tests are the contract,
   not the sketch.
2. **The `Entry` change in Task 4.** Attaching a block kind to each line may
   turn out to be unnecessary if `baseStyle` can take the kind as a parameter
   from `paint`'s loop. Take the smaller change if it works.
3. **Row counts in the tests.** Several assert exact row numbers computed by
   hand from the wrap rules. Where one is wrong, check the renderer *first* —
   the property test in Task 6 is the arbiter, not the arithmetic in this
   document.

Execute with `executing-plans`, sequentially. The tasks share one file from
Task 3 onward, so they are not independent and parallel execution would only
create conflicts.
