# tug v0.1 «Hull» — Phase 5 «Mock provider» Implementation Plan

> **To execute:** use the `executing-plans` skill. Steps use `- [ ]` for tracking.

**Goal:** Ship Phase 5 of `.artifacts/v0.0.md` — a seeded, deterministic mock
provider behind the interface v0.2's real providers will use, a cadence engine
that decides how its bytes arrive, seven named fault modes, and the proof that a
firehose still paints at the frame budget.

**Architecture:** Three layers, matching the split the roadmap already committed
to. `tugcore` decides **what** is said: a seeded PRNG assembles markdown-rich
units and emits the full `StreamEvent` sequence, freestanding and
allocation-free. `tugshell` decides **how it arrives**: a cadence engine chunks
and delays, and a provider thread pushes those chunks onto the Phase-3 queue and
rings the waker. The loop, the bus and the renderer are untouched — whether that
holds is the real test of whether Phases 3 and 4 built the right seam.

Between those two layers sits the ownership problem Phase 3 deferred in
`queue.zig`: a queued payload's slice is borrowed, and its producer's stack frame
is long gone by the time the loop publishes it. This phase is the first with a
real cross-thread producer, so it is the phase that decides — **the queue copies
bytes into its own slots** (`DR-010`).

**Tech stack:** Zig 0.16.0, pinned via `minimum_zig_version` in `build.zig.zon`.
No third-party dependencies. `std.Random.DefaultPrng` (Xoshiro256 — pure
arithmetic, so freestanding-safe) for determinism, `std.Thread` and `io.sleep`
for the provider thread, `std.Io.Writer` for output.

### Zig 0.16 API notes

Facts established by reading the pinned standard library and by running a probe
against it, so no task has to guess:

- `std.Random.DefaultPrng` is `Xoshiro256`. Construct with
  `std.Random.DefaultPrng.init(seed)`, take a `std.Random` with
  `prng.random()`, and draw with `random.uintLessThan(usize, n)` or
  `random.intRangeLessThan(u32, lo, hi)`. Pure arithmetic, so it compiles for
  `wasm32-freestanding`.
- **Sleeping is `io.sleep(duration, clock)`.** `std.Thread.sleep` does not exist
  in 0.16. The signature is `pub fn sleep(io: Io, duration: Duration, clock:
  Clock) Cancelable!void`, and `std.Io.Duration.fromMilliseconds(i64)` builds
  the argument. Use `.awake`, matching `waiting.nowMs`.
- **`io.sleep` works from a spawned `std.Thread` on an `Io` obtained from
  `std.Io.Threaded.init_single_threaded`.** Verified by probe, because the whole
  cadence engine rests on it: a 20 ms sleep on the main thread and a 10 ms sleep
  on a spawned thread both returned normally.
- `std.Thread.spawn(.{}, Func, .{args})` returns `std.Thread`; `.join()` waits.
  `queue.zig`'s existing multi-producer test is the model to copy.
- `std.atomic.Value(bool)` with `.init(false)`, `.load(.acquire)` and
  `.store(true, .release)` is the stop flag: the loop thread sets it, the
  provider thread reads it.
- `std.ArrayList(T)` **is** `ArrayListUnmanaged`. Init with `.empty`; every
  mutating method takes the allocator first.
- `std.Io.Writer.fixed(&buf)` fails with `error.WriteFailed` when the buffer
  fills; `buffered()` returns what is in it.
- `std.unicode.utf8ByteSequenceLength(first_byte) !u3` reports how many bytes a
  lead byte claims. `split_utf8` uses it to find a cut that lands *inside* a
  codepoint rather than between two.

### Facts about this codebase the tasks depend on

- `proto.StreamEvent` is `union(enum) { text_delta: []const u8, usage: Usage,
  stop: Stop, err: Err }`. `Usage` is `{ input_tokens: u32 = 0, output_tokens:
  u32 = 0 }`, `Stop` is `{ reason: StopReason }`, `Err` is `{ kind: ErrKind,
  message: []const u8 }`. **Do not add a variant** — that is a wire-format change
  and belongs at a version boundary.
- `proto.Payload` is the bus catalog. Exactly three arms carry a borrowed slice:
  `input_submit.text`, `stream_delta.text`, `err.message`. Every other arm is
  `void`. Task 4 depends on that list being exactly three.
- `core.Bus.Subscriber` is `{ context: ?*anyopaque = null, handler: *const fn
  (context: ?*anyopaque, payload: proto.Payload) void }`. Task 1's seam copies
  that shape deliberately: an erased context plus one function pointer is
  already this codebase's idiom for a seam, and a second idiom would be a second
  thing to learn.
- `core.Scheduler` caps paints at `default_frame_ms = 8` and already has the
  unit test proving a burst of `markDirty` between paints costs one paint. Task
  9 does not re-test that; it tests that a **real thread** pushing at an
  unbounded rate does not defeat it.
- `shell.Renderer.feed(bytes)` copies into its own storage, so a delta's bytes
  only have to survive until the loop publishes them. That is what makes Task
  4's slot copy sufficient rather than needing refcounts.
- `shell.Waker.wake()` coalesces: at most one byte is ever in the pipe, so a
  producer may ring it on every push and never block.
- `src/shell/render/golden.zig` holds `escape` and `readGolden` as private
  functions. Task 8 needs both, so Task 8 extracts them rather than copying.

### Where each fault mode is honoured

The spec names seven modes under one flag. They do not all live in one place,
and pretending they did would put a clock in `tugcore`. One enum, two honourers,
and the enum's doc comment says which is which:

| Mode | Honoured by | What it does |
|---|---|---|
| `stall` | cadence | Sleeps `stall_ms` before the fourth chunk. |
| `midstream_error` | core | Halfway through, emits `err` then `stop{.err}`. |
| `oversized_chunk` | core | The first delta is `max_delta_bytes` long. |
| `split_utf8` | cadence | Cuts a chunk inside a multi-byte codepoint. |
| `instant` | cadence | Whole-remaining chunks, zero delay. |
| `firehose` | core **and** cadence | Core multiplies the unit count; cadence sets zero delay. |
| `empty` | core | `usage` and `stop`, no deltas at all. |

```zig
//! The provider seam.
//!
//! A provider is a blocking iterator of `StreamEvent` and nothing else. It has
//! no idea what a socket is, no idea what a terminal is, and no opinion about
//! how fast its events should arrive — that is the cadence engine's job, one
//! layer out, where the clock lives.
//!
//! One function pointer and an erased context, which is the same shape
//! `Bus.Subscriber` already uses. There is deliberately no `deinit`, no
//! `cancel` and no error union: a provider that fails says so by emitting an
//! `err` event, because that is the failure the renderer already knows how to
//! draw. v0.2's HTTP provider satisfies this signature without either side
//! changing, which is the entire point of writing it a version early.

const std = @import("std");

const proto = @import("tugproto");

pub const Provider = struct {
    context: ?*anyopaque = null,

    /// The next event, or null once the stream is over. Blocking: a real
    /// provider sits in a read here, which is why it runs on its own thread.
    next: *const fn (context: ?*anyopaque) ?proto.StreamEvent,

    pub fn nextEvent(self: Provider) ?proto.StreamEvent {
        return self.next(self.context);
    }
};
```

And in `src/core/root.zig`, beside the existing exports:

```zig

pub const Provider = provider.Provider;
```

fn drain(config: Config, sink: []u8) ![]const u8 {

- [ ] **Step 3: Minimal implementation**

`src/core/mock.zig`. The generator assembles **units** — one heading, paragraph,
bullet list, ordered list, fence, or CJK paragraph — into a fixed buffer the
`Mock` owns, and emits each finished unit as one `text_delta`. Chunking is
explicitly not its business; the cadence engine re-cuts these deltas into
whatever sizes it wants.

```zig
//! The mock provider: a seeded generator of markdown-rich responses.
//!
//! Deterministic to the byte. The same seed produces the same response on every
//! platform and in every optimize mode, because the only source of variety is a
//! Xoshiro256 draw over a fixed corpus — no clock, no allocator, no hash order.
//! That is what makes it usable as the input side of a golden test.
//!
//! It decides *what* is said and emits whole logical units. It has no opinion
//! about how fast they arrive or how they are cut up, because both need a clock
//! and this module compiles for `wasm32-freestanding`. Timing lives in
//! `tugshell/provider/cadence.zig`.

const std = @import("std");

const proto = @import("tugproto");
const Provider = @import("provider.zig").Provider;

/// The largest single `text_delta`. Sized by `oversized_chunk`, which exists to
/// be far larger than the queue's 512-byte slot so the runner has to split it
/// and then feel the backpressure — 8 KiB is sixteen slots' worth.
pub const max_delta_bytes: usize = 8 * 1024;

/// How many units `firehose` emits. Large enough that the response is measured
/// in megabytes rather than kilobytes, which is what makes the frame-rate proof
/// mean anything.
///
/// ponytail: tuned by measurement, not derivation — `scripts/mock-modes.sh`
/// wants a run of at least two seconds. If a faster machine finishes sooner,
/// raise this rather than lowering the assertion.
pub const firehose_units: u16 = 20_000;

/// The named fault modes.
///
/// Two of them are honoured here and five in the cadence engine, because a
/// fault about *timing* or *chunk boundaries* cannot be expressed by a module
/// with no clock and no say in chunking. The enum is shared so the flag stays
/// one flag; see the table in this phase's plan.
pub const Fault = enum {
    none,
    /// Cadence: pauses mid-stream.
    stall,
    /// Core: gives up halfway through.
    midstream_error,
    /// Core: one absurdly large delta.
    oversized_chunk,
    /// Cadence: cuts a chunk inside a codepoint.
    split_utf8,
    /// Cadence: no delay at all.
    instant,
    /// Core and cadence: no delay, and megabytes of it.
    firehose,
    /// Core: a response with no text in it.
    empty,

    pub fn parse(text: []const u8) ?Fault {
        return std.meta.stringToEnum(Fault, text);
    }
};

pub const Config = struct {
    seed: u64 = 0,
    fault: Fault = .none,
    /// Logical units before the stream ends. `firehose` overrides it.
    units: u16 = 8,
    stall_ms: u32 = 1500,
};

const Unit = enum { heading, paragraph, bullets, ordered, fence, wide };

/// Sentence fragments, drawn from by index. Fixed content on purpose: a corpus
/// that changed would change every golden in the repo.
const sentences = [_][]const u8{
    "A tugboat's power is rated in **bollard pull**, and the number is absurd for its size.",
    "One static binary, no runtime, no telemetry, and a budget that CI enforces.",
    "The core is a *freestanding library*; the CLI is merely its first frontend.",
    "Every token the harness injects into a context is a cost somebody pays.",
    "Anything measurable gets a budget, and budgets are enforced by CI rather than by intentions.",
    "If a feature can be a plugin then it is a plugin, and the bar for core is that the harness is broken without it.",
};

const headings = [_][]const u8{ "Bollard pull", "Budgets", "The seam", "What ships" };

const items = [_][]const u8{
    "a shell, a loop, two providers, four tools",
    "one write per frame, and the row count exact",
    "wrap to the terminal width, never to a guess",
    "repaint the tail, never the scrollback",
};

const fence_body =
    \\```zig
    \\pub fn main() !void {
    \\    // **not bold** inside a fence
    \\    std.debug.print("ship it\n", .{});
    \\}
    \\```
;

const wide_text = "日本語のテキストも折り返します。 🚢 And back to *ASCII* again.";

/// Where the generator is in the fixed tail of every response.
const Phase = enum { text, usage, stop, done };

pub const Mock = struct {
    config: Config,
    prng: std.Random.DefaultPrng,
    buffer: [max_delta_bytes]u8 = undefined,
    emitted: u16 = 0,
    bytes_out: u32 = 0,
    phase: Phase = .text,

    pub fn init(config: Config) Mock {
        return .{ .config = config, .prng = .init(config.seed) };
    }

    pub fn provider(self: *Mock) Provider {
        return .{ .context = self, .next = nextErased };
    }

    fn nextErased(context: ?*anyopaque) ?proto.StreamEvent {
        const self: *Mock = @ptrCast(@alignCast(context.?));
        return self.next();
    }

    fn totalUnits(self: *const Mock) u16 {
        return switch (self.config.fault) {
            .firehose => firehose_units,
            .empty => 0,
            else => self.config.units,
        };
    }

    pub fn next(self: *Mock) ?proto.StreamEvent {
        switch (self.phase) {
            .text => {
                if (self.emitted >= self.totalUnits()) {
                    self.phase = .usage;
                    return self.next();
                }
                const text = self.renderUnit();
                self.emitted += 1;
                self.bytes_out += @intCast(text.len);
                return .{ .text_delta = text };
            },
            .usage => {
                self.phase = .stop;
                // Four bytes to a token is the estimate every provider uses
                // when it has nothing better, and v0.1 has nothing better.
                return .{ .usage = .{
                    .input_tokens = 12,
                    .output_tokens = @max(1, self.bytes_out / 4),
                } };
            },
            .stop => {
                self.phase = .done;
                return .{ .stop = .{ .reason = .end_turn } };
            },
            .done => return null,
        }
    }

    /// Writes one unit into the buffer and returns it. The slice is valid until
    /// the next call, which is exactly the borrow `StreamEvent` documents.
    fn renderUnit(self: *Mock) []const u8 {
        var random = self.prng.random();
        const unit: Unit = @enumFromInt(random.uintLessThan(usize, @typeInfo(Unit).@"enum".fields.len));

        var writer: std.Io.Writer = .fixed(&self.buffer);
        switch (unit) {
            .heading => writer.print("# {s}\n\n", .{pick(&random, &headings)}) catch {},
            .paragraph => writer.print("{s}\n{s}\n\n", .{
                pick(&random, &sentences),
                pick(&random, &sentences),
            }) catch {},
            .bullets => {
                for (0..3) |_| writer.print("- {s}\n", .{pick(&random, &items)}) catch {};
                writer.writeAll("\n") catch {};
            },
            .ordered => {
                for (1..4) |n| writer.print("{d}. {s}\n", .{ n, pick(&random, &items) }) catch {};
                writer.writeAll("\n") catch {};
            },
            .fence => writer.print("{s}\n\n", .{fence_body}) catch {},
            .wide => writer.print("{s}\n\n", .{wide_text}) catch {},
        }
        return writer.buffered();
    }
};

fn pick(random: *std.Random, table: []const []const u8) []const u8 {
    return table[random.uintLessThan(usize, table.len)];
}
```

/// The largest text a single queued payload may carry. Chosen against the
/// producer, not the consumer: the cadence engine's largest ordinary chunk is
/// 64 bytes, and a fault that sends more splits across slots on the way in.
/// 64 slots at this size is 32 KiB of static footprint against a 10 MiB RSS
/// budget.
pub const max_payload_bytes: usize = 512;

const Slot = struct {
    payload: proto.Payload = .session_start,
    bytes: [max_payload_bytes]u8 = undefined,
    len: usize = 0,
};

/// The borrowed slice a payload carries, or an empty one. Exactly three arms of
/// the catalog carry bytes; a new one added later without touching this
/// function would be silently dropped, so this switch is deliberately explicit
/// rather than an `else`.
fn payloadBytes(payload: proto.Payload) []const u8 {
    return switch (payload) {
        .input_submit => |p| p.text,
        .stream_delta => |p| p.text,
        .err => |p| p.message,
        .session_start, .request_start, .stream_end => "",
        .tool_request, .tool_decision, .tool_result => "",
        .turn_end, .shutdown => "",
    };
}

/// The same payload with its slice repointed at `bytes`.
fn withBytes(payload: proto.Payload, bytes: []const u8) proto.Payload {
    return switch (payload) {
        .input_submit => .{ .input_submit = .{ .text = bytes } },
        .stream_delta => .{ .stream_delta = .{ .text = bytes } },
        .err => .{ .err = .{ .message = bytes } },
        else => payload,
    };
}
```

`push` copies into the slot under the lock:

```zig
    pub fn push(self: *Queue, io: std.Io, payload: proto.Payload) error{ Full, PayloadTooLarge }!void {
        const bytes = payloadBytes(payload);
        if (bytes.len > max_payload_bytes) return error.PayloadTooLarge;

        self.mutex.lockUncancelable(io);
        defer self.mutex.unlock(io);

        if (self.len == capacity) return error.Full;
        const slot = &self.items[(self.head + self.len) % capacity];
        @memcpy(slot.bytes[0..bytes.len], bytes);
        slot.len = bytes.len;
        slot.payload = payload;
        self.len += 1;
    }
```

`pop` copies back out, still under the lock, into the caller's buffer:

```zig
    /// Copies into `out` rather than returning a slice into the ring, because
    /// the slot is free the instant this returns and a producer may refill it
    /// before the caller has published. `out` must outlive the returned
    /// payload; the loop's is a local in `drainQueue`, which is exactly the
    /// publish-and-forget lifetime the bus documents.
    pub fn pop(self: *Queue, io: std.Io, out: *[max_payload_bytes]u8) ?proto.Payload {
        self.mutex.lockUncancelable(io);
        defer self.mutex.unlock(io);

        if (self.len == 0) return null;
        const slot = &self.items[self.head];
        @memcpy(out[0..slot.len], slot.bytes[0..slot.len]);
        const payload = withBytes(slot.payload, out[0..slot.len]);
        self.head = (self.head + 1) % capacity;
        self.len -= 1;
        return payload;
    }
```

- [ ] **Step 5: Write DR-010**

`docs/decisions/DR-010-queue-owns-bytes.md`, following `DR-002`'s structure.
The content, in the repo's own voice:

- **Context.** `StreamEvent` and `Payload` both document their slices as
  borrowed, which is right for the single-threaded path — the renderer copies on
  `feed`, so nothing else needs to own anything. It stops being right the moment
  a producer on another thread queues a payload: the producer's buffer is reused
  for the next chunk long before the loop drains.
- **Options.** (1) An arena drained alongside the queue — needs an allocator in
  the hot path and a second lifetime to reason about. (2) A byte pool behind the
  queue — needs the consumer to say when it is done, which is a refcount.
  (3) Fixed-size slots that own their bytes — one memcpy each way, no allocator,
  no lifetime question.
- **Decision.** Option 3, at 512 bytes and 64 slots: 32 KiB static, against a
  10 MiB RSS budget. `pop` copies out under the lock because a slot is free the
  instant `pop` returns.
- **Consequences.** A payload larger than a slot is refused with
  `PayloadTooLarge`, and splitting it is the producer's job — which is free,
  because a text delta split in two is two text deltas. The bound is what makes
  a firehose apply backpressure instead of growing memory. Revisit if a payload
  arrives that cannot be split; nothing in v0.1 has one.

```zig
//! The cadence engine: how fast a response arrives, and where it is cut.
//!
//! The mock decides what is said; this decides how it is delivered. The split
//! is not tidiness — cadence needs a clock and a say in chunk boundaries, and
//! `tugcore` has neither. It is also the layer a real provider will *not* have:
//! v0.2's HTTP provider gets its cadence from the network, and this file is
//! what stands in for the network until then.
//!
//! Pure: no clock, no IO. `delayMs` returns a number of milliseconds and the
//! runner is what sleeps, which is what makes every case below testable without
//! a single real millisecond passing.

const std = @import("std");

const core = @import("tugcore");
const mock = core.mock;
const queue = @import("../loop/queue.zig");

/// The ordinary chunk range. Small enough that a wrapped paragraph arrives over
/// several frames — which is the thing worth watching for flicker — and capped
/// well under the queue's slot size so a chunk is never refused.
pub const min_chunk_bytes: usize = 8;
pub const max_chunk_bytes: usize = 64;

/// The ordinary delay range. Roughly a real provider's token rate: 4 ms is
/// faster than anything ships, 40 ms is a slow one under load.
pub const min_delay_ms: u32 = 4;
pub const max_delay_ms: u32 = 40;

/// Which chunk the stall lands on. Late enough that a block is open and partly
/// painted, early enough that the response is visibly unfinished.
const stall_at_chunk: u32 = 3;

comptime {
    // The runner pushes a chunk straight into a queue slot. If this ever stops
    // holding, the failure is a runtime PayloadTooLarge in the middle of a
    // stream rather than a message here.
    std.debug.assert(max_chunk_bytes <= queue.max_payload_bytes);
}

pub const Preset = enum {
    normal,
    instant,
    firehose,

    pub fn parse(text: []const u8) ?Preset {
        return std.meta.stringToEnum(Preset, text);
    }
};

/// Faults that are *about* timing pick their own preset; the rest leave the
/// user's `--mock-cadence` alone.
pub fn presetFor(fault: mock.Fault, requested: Preset) Preset {
    return switch (fault) {
        .instant => .instant,
        .firehose => .firehose,
        else => requested,
    };
}

pub const Cadence = struct {
    preset: Preset,
    fault: mock.Fault,
    stall_ms: u32,
    prng: std.Random.DefaultPrng,
    chunks: u32 = 0,
    stalled: bool = false,

    pub fn init(seed: u64, preset: Preset, fault: mock.Fault, stall_ms: u32) Cadence {
        // A different stream from the mock's, so changing the cadence does not
        // change what is said. Same seed in, same cadence out.
        return .{
            .preset = preset,
            .fault = fault,
            .stall_ms = stall_ms,
            .prng = .init(seed ^ 0x9e37_79b9_7f4a_7c15),
        };
    }

    pub fn chunkLen(self: *Cadence, remaining: []const u8) usize {
        if (remaining.len == 0) return 0;
        if (self.fault == .split_utf8) {
            if (splitInsideCodepoint(remaining)) |cut| return cut;
        }
        return switch (self.preset) {
            .instant, .firehose => @min(remaining.len, queue.max_payload_bytes),
            .normal => @min(
                remaining.len,
                min_chunk_bytes + self.prng.random().uintLessThan(
                    usize,
                    max_chunk_bytes - min_chunk_bytes + 1,
                ),
            ),
        };
    }

    pub fn delayMs(self: *Cadence) u32 {
        self.chunks += 1;
        if (self.fault == .stall and !self.stalled and self.chunks >= stall_at_chunk) {
            self.stalled = true;
            return self.stall_ms;
        }
        return switch (self.preset) {
            .instant, .firehose => 0,
            .normal => min_delay_ms +
                self.prng.random().uintLessThan(u32, max_delay_ms - min_delay_ms + 1),
        };
    }
};

/// A cut length that lands strictly inside the first multi-byte codepoint, or
/// null when there is none to land inside.
fn splitInsideCodepoint(bytes: []const u8) ?usize {
    var index: usize = 0;
    while (index < bytes.len) {
        const length = std.unicode.utf8ByteSequenceLength(bytes[index]) catch {
            index += 1;
            continue;
        };
        if (length > 1 and index + length <= bytes.len) return index + 1;
        index += length;
    }
    return null;
}
```

Note the `.instant`/`.firehose` chunk length is capped at

`oversized_chunk` path: the mock's 8 KiB delta reaches the runner whole and is
split into sixteen slot-sized pushes, which is the backpressure the fault exists
to exercise. Raising the cap to make a test pass would delete that path.

```zig
//! The provider thread.
//!
//! Pull an event, cut it to the cadence's chunk size, wait the cadence's delay,
//! push it on the queue, ring the waker. That is the whole of it, and it is the
//! shape every real provider will have in v0.2 — only the `Provider` behind it
//! changes, and it changes on the other side of a seam this file never looks
//! through.
//!
//! It runs on its own thread because `Provider.nextEvent` is documented as
//! blocking. The only things it shares with the loop are the queue, which has a
//! mutex, the waker, which coalesces and cannot block, and one atomic bool.
//!
//! Backpressure is the interesting part. The queue is 64 fixed slots, so a
//! producer that outruns the loop gets `error.Full` rather than growing memory.
//! The answer is to ring the doorbell and wait a millisecond: the loop is
//! behind, and the correct thing for a producer to do about that is nothing,
//! slowly.

const std = @import("std");

const core = @import("tugcore");
const proto = @import("tugproto");

const cadence_mod = @import("cadence.zig");
const queue_mod = @import("../loop/queue.zig");
const waiting = @import("../loop/wait.zig");

const Cadence = cadence_mod.Cadence;
const Queue = queue_mod.Queue;
const Waker = waiting.Waker;

/// How long to wait before retrying a push onto a full queue. One millisecond
/// is roughly an eighth of a frame: long enough not to spin, short enough that
/// the producer is ready the moment the loop drains.
pub const backpressure_ms: u32 = 1;

pub const Runner = struct {
    io: std.Io,
    provider: core.Provider,
    cadence: *Cadence,
    queue: *Queue,
    waker: *Waker,
    stop: *std.atomic.Value(bool),

    pub fn spawn(self: *Runner) std.Thread.SpawnError!std.Thread {
        return std.Thread.spawn(.{}, run, .{self});
    }

    /// Never fails. A provider thread that returned an error would have nowhere
    /// to return it to, so every failure it can actually have — a full queue,
    /// an interrupted sleep — is handled here, and the one the *user* needs to
    /// know about arrives as an `err` payload like any other event.
    pub fn run(self: *Runner) void {
        self.send(.request_start);

        while (!self.stop.load(.acquire)) {
            const event = self.provider.nextEvent() orelse break;
            switch (event) {
                .text_delta => |bytes| self.sendText(bytes),
                .err => |e| self.send(.{ .err = .{ .message = e.message } }),
                // v0.1 has nowhere to show a token count. The event exists so
                // the seam is complete; `/context` in v0.3 is what consumes it.
                .usage => {},
                .stop => break,
            }
        }

        self.send(.stream_end);
        self.send(.turn_end);
    }

    /// Cuts one delta into chunks the queue can hold, pacing each one.
    fn sendText(self: *Runner, bytes: []const u8) void {
        var rest = bytes;
        while (rest.len > 0) {
            if (self.stop.load(.acquire)) return;

            const take = self.cadence.chunkLen(rest);
            if (take == 0) return;

            const delay = self.cadence.delayMs();
            if (delay > 0) self.io.sleep(.fromMilliseconds(delay), .awake) catch return;

            self.send(.{ .stream_delta = .{ .text = rest[0..take] } });
            rest = rest[take..];
        }
    }

    /// Pushes, retrying while the queue is full. Rings the waker either way —
    /// on a full queue the ring is the point, since it is what gets the loop
    /// draining again.
    fn send(self: *Runner, payload: proto.Payload) void {
        while (!self.stop.load(.acquire)) {
            self.queue.push(self.io, payload) catch |err| switch (err) {
                error.Full => {
                    self.waker.wake();
                    self.io.sleep(.fromMilliseconds(backpressure_ms), .awake) catch return;
                    continue;
                },
                // The cadence caps chunks below the slot size and every other
                // payload here is a fixed string, so this is unreachable in
                // practice. Dropping it beats a panic on a background thread.
                error.PayloadTooLarge => return,
            };
            self.waker.wake();
            return;
        }
    }
};

/// Debug flags, so a bad value degrades to the default rather than refusing to
/// start. `--provider` is the one that decides the command; the rest only
/// configure it, and are ignored when no provider was asked for.
fn parseArgs(argv: []const [:0]const u8) Options {
    var options: Options = .{};
    var requested_cadence: shell.cadence.Preset = .normal;

    const args = argv[@min(1, argv.len)..];
    var index: usize = 0;
    while (index < args.len) : (index += 1) {
        const arg = args[index];
        const value: ?[]const u8 = if (index + 1 < args.len) args[index + 1] else null;

        if (eqlAny(arg, &.{ "--version", "-V" })) return .{ .command = .version };
        if (eqlAny(arg, &.{ "--help", "-h" })) return .{ .command = .help };
        if (eqlAny(arg, &.{"--caps"})) return .{ .command = .caps };
        if (eqlAny(arg, &.{"--debug-keys"})) return .{ .command = .debug_keys };

        if (eqlAny(arg, &.{"--provider"})) {
            if (value) |name| {
                if (std.mem.eql(u8, name, "mock")) options.command = .mock;
                index += 1;
            }
        } else if (eqlAny(arg, &.{"--mock-seed"})) {
            if (value) |text| {
                options.mock.seed = std.fmt.parseInt(u64, text, 10) catch options.mock.seed;
                index += 1;
            }
        } else if (eqlAny(arg, &.{"--mock-fault"})) {
            if (value) |text| {
                parseFault(text, &options.mock);
                index += 1;
            }
        } else if (eqlAny(arg, &.{"--mock-cadence"})) {
            if (value) |text| {
                requested_cadence = shell.cadence.Preset.parse(text) orelse requested_cadence;
                index += 1;
            }
        }
    }

    options.cadence = shell.cadence.presetFor(options.mock.fault, requested_cadence);
    return options;
}

    const name = if (split) |at| text[0..at] else text;

        config.stall_ms = std.fmt.parseInt(u32, text[at + 1 ..], 10) catch config.stall_ms;

```zig
const MockSession = struct {
    renderer: *shell.Renderer,
    screen: *std.Io.Writer,
    terminal: *shell.Backend,
    stop: *std.atomic.Value(bool),
    failed: ?anyerror = null,
    finished: bool = false,

    fn onEvent(context: ?*anyopaque, payload: shell.proto.Payload) void {
        const self: *MockSession = @ptrCast(@alignCast(context.?));
        self.apply(payload) catch |err| {
            self.failed = err;
        };
    }

    fn apply(self: *MockSession, payload: shell.proto.Payload) !void {
        switch (payload) {
            .request_start => try self.renderer.beginBlock(.assistant),
            .stream_delta => |d| try self.renderer.feed(d.text),
            .err => |e| {
                try self.renderer.beginBlock(.notice);
                try self.renderer.feed(e.message);
                try self.renderer.feed("\n");
            },
            .stream_end => try self.renderer.endBlock(),
            .turn_end => self.finished = true,
            else => {},
        }
    }

    fn onInput(context: ?*anyopaque, event: shell.InputEvent) shell.loop.Flow {
        const self: *MockSession = @ptrCast(@alignCast(context.?));
        return switch (event) {
            .key => |k| if (k.mods.ctrl and k.key.eql(.{ .char = 'c' })) blk: {
                self.stop.store(true, .release);
                break :blk .stop;
            } else .keep_going,
            .paste => .keep_going,
        };
    }

    fn onRender(context: ?*anyopaque) anyerror!void {
        const self: *MockSession = @ptrCast(@alignCast(context.?));
        if (self.failed) |err| return err;
        self.renderer.setSize(self.terminal.size());
        _ = try self.renderer.paint(self.screen);
        try self.screen.flush();
        // The turn is over and there is no editor yet to hand control to, so
        // the honest thing is to leave. Phase 6 replaces this with a prompt.
        if (self.finished) return error.TurnFinished;
    }
};

    );

    defer renderer.deinit();

    defer frames.deinit(gpa);

    var sink: [256 * 1024]u8 = undefined;

        fn paint(r: *renderer_mod.Renderer, buf: []u8, out: []u8, into: *std.ArrayList(u8), alloc: std.mem.Allocator) !void {
            var counting: Counting = .init(buf, out);
            _ = try r.paint(&counting.writer);
            try counting.writer.flush();
            try testing.expect(counting.writes <= 1);
            try into.appendSlice(alloc, counting.bytes());
        }
    }.paint;

    try renderer.beginBlock(.assistant);
    while (m.next()) |event| switch (event) {
        .text_delta => |bytes| {
            var rest = bytes;
            while (rest.len > 0) {
                const take = c.chunkLen(rest);
                _ = c.delayMs();
                try renderer.feed(rest[0..take]);
                rest = rest[take..];
                since_paint += 1;
                if (since_paint >= paint_every) {
                    since_paint = 0;
                    try painter(&renderer, &buffer, &sink, &frames, gpa);
                }
            }
        },
        .err => |e| {
            try renderer.beginBlock(.notice);
            try renderer.feed(e.message);
            try renderer.feed("\n");
        },
        .usage, .stop => {},
    };
    try renderer.endBlock();
    try painter(&renderer, &buffer, &sink, &frames, gpa);

    try transcript.expectGolden(gpa, name, frames.items);
}

### Task 9: The firehose coalescing proof

**Files:**
- Create: `src/shell/provider/firehose_test.zig`
- Modify: `src/shell/root.zig` (register the file in the test block)

**Interfaces:**
- Consumes: `Runner`, `Cadence`, `Queue`, `Waker`, `core.Scheduler`,
  `Renderer`, `Counting`, `waiting.nowMs`.
- Produces: nothing importable. This file is a test.

The claim under test, from the spec: *at unbounded input rate, write count stays
≤ ~125/sec and CPU stays sane.* `Scheduler` is already unit-tested for the
coalescing arithmetic. What is not tested is whether a **real thread pushing as
fast as it can** defeats it, which is a race, not arithmetic — so this test uses
a real clock and real wall time.

It does not use `Loop.run`, which needs a terminal file descriptor no portable
test can produce. It uses the same four pieces the loop uses, in the same order:
drain the queue, mark the scheduler, paint when due. What stays untested is
`Loop.run`'s own body, and Task 10's pty script is what covers that. Say so in
the phase notes rather than claiming otherwise.

- [ ] **Step 1: Write the failing test**

```zig
//! The firehose proof.
//!
//! Half a second of a real provider thread pushing as fast as the queue will
//! take it, against a consumer that paints only when the scheduler says to. The
//! number that matters is writes per second, and the budget is the frame
//! interval: 8 ms, so 125.

const std = @import("std");
const testing = std.testing;

const core = @import("tugcore");
const Counting = @import("../render/counting_writer.zig").Counting;
const renderer_mod = @import("../render/renderer.zig");
const cadence_mod = @import("cadence.zig");
const runner_mod = @import("runner.zig");
const queue_mod = @import("../loop/queue.zig");
const waiting = @import("../loop/wait.zig");

const run_ms: u64 = 500;

/// The budget plus a quarter. The slack is for a CI runner that schedules the
/// consumer thread late and then finds two frames due at once; it is not slack
/// for a renderer that paints per delta, which would be off by an order of
/// magnitude rather than by 25 %.
fn frameBudget(elapsed_ms: u64) usize {
    return @intCast(2 + (elapsed_ms * 125 * 5) / (1000 * 4));
}

test "a firehose still paints at the frame budget" {
    const gpa = testing.allocator;

    var threaded: std.Io.Threaded = .init_single_threaded;
    const io = threaded.io();

    var m: core.mock.Mock = .init(.{ .seed = 31, .fault = .firehose });
    var c: cadence_mod.Cadence = .init(31, .firehose, .firehose, 0);
    var q: queue_mod.Queue = .{};
    var waker: waiting.Waker = try .init();
    defer waker.deinit();
    var stop: std.atomic.Value(bool) = .init(false);

    var runner: runner_mod.Runner = .{
        .io = io,
        .provider = m.provider(),
        .cadence = &c,
        .queue = &q,
        .waker = &waker,
        .stop = &stop,
    };
    const thread = try runner.spawn();

    var caps: renderer_mod.Capabilities = .{
        .color = .none,
        .kitty_keyboard = false,
        .synchronized_output = false,
        .bracketed_paste = true,
        .size = .{ .cols = 80, .rows = 24 },
    };
    var renderer: renderer_mod.Renderer = .init(gpa, caps, caps.size);
    defer renderer.deinit();
    try renderer.beginBlock(.assistant);

    var scheduler: core.Scheduler = .{};
    var buffer: [256 * 1024]u8 = undefined;
    var sink: [1024 * 1024]u8 = undefined;
    var counting: Counting = .init(&buffer, &sink);

    var out: [queue_mod.max_payload_bytes]u8 = undefined;
    const start = waiting.nowMs(io);
    var bytes_seen: usize = 0;

    while (true) {
        const now = waiting.nowMs(io);
        if (now - start >= run_ms) break;

        while (q.pop(io, &out)) |payload| switch (payload) {
            .stream_delta => |d| {
                try renderer.feed(d.text);
                bytes_seen += d.text.len;
                scheduler.markDirty();
            },
            else => scheduler.markUrgent(),
        };

        if (scheduler.due(now)) {
            // The sink is reused every frame: this measures write *count*, and
            // a megabyte of retained frames would measure nothing but memory.
            counting.len = 0;
            _ = try renderer.paint(&counting.writer);
            try counting.writer.flush();
            scheduler.painted(now);
        }
    }

    stop.store(true, .release);
    while (q.pop(io, &out)) |_| {}
    thread.join();

    const elapsed = waiting.nowMs(io) - start;

    // The firehose has to have actually been a firehose, or the frame count
    // proves nothing: a producer that never started also paints zero times.
    try testing.expect(bytes_seen > 256 * 1024);
    try testing.expect(counting.writes <= frameBudget(elapsed));
}
```

Note `counting.len = 0` before each paint: the renderer's own one-write-per-frame
invariant is already asserted by every golden, and re-asserting it here would
mean retaining every frame of a firehose.

- [ ] **Step 2: Run it, confirm it fails**

Expect: FAIL — the file is not registered in `src/shell/root.zig`'s test block,

What this covers that Task 8 does not: the flags are wired to the code, the
process exits on its own, the loop's own body runs, and the terminal is left

transcripts — a pty capture depends on `TERM`, the window size and the
capability probe's timing, and a byte-exact assertion over that is a flaky test

where they are stable.

- [ ] **Step 1: Write the script**

`scripts/mock-modes.sh`, modelled on `scripts/exit-paths.sh` — same skip-rather-
than-lie posture, same `set -eu`:

```sh
#!/bin/sh
# Every fault mode, through a real pty, in the real binary.
#
# The goldens in `src/shell/provider/golden.zig` already pin the bytes the
# renderer produces. What they cannot check is whether the flags reach the code,
# whether the process exits on its own, and whether the loop's own body — which
# no portable unit test can drive, since it needs a terminal — survives each
# mode. That is this script.
#
# usage: mock-modes.sh <binary>
set -eu

binary=${1:-zig-out/bin/tug}

if ! command -v script >/dev/null 2>&1; then
    echo "mock-modes: no script(1); skipping" >&2
    exit 0
fi

capture=$(mktemp)
trap 'rm -f "$capture"' EXIT

run() {
    mode=$1
    shift
    if ! timeout 30 script -qec "$binary --provider mock --mock-seed 1 $*" /dev/null \
        >"$capture" 2>&1; then
        printf 'mock-modes: %s did not exit cleanly\n' "$mode" >&2
        exit 1
    fi
}

# --- each mode exits on its own ----------------------------------------------

for fault in none stall=50 midstream_error oversized_chunk split_utf8 instant empty; do
    run "$fault" "--mock-fault $fault"
    printf 'mock-modes: %s ok (%s bytes)\n' "$fault" "$(wc -c <"$capture")"
done

# --- midstream_error says so -------------------------------------------------

run midstream_error "--mock-fault midstream_error"
if ! grep -q "hung up mid-stream" "$capture"; then
    echo "mock-modes: midstream_error did not print its notice" >&2
    exit 1
fi
echo "mock-modes: midstream_error notice ok"

# --- empty says nothing ------------------------------------------------------

run empty "--mock-fault empty"
if grep -q "bollard pull" "$capture"; then
    echo "mock-modes: empty streamed a response" >&2
    exit 1
fi
echo "mock-modes: empty ok"

# --- determinism -------------------------------------------------------------

run first "--mock-fault instant"
cp "$capture" "$capture.first"
run second "--mock-fault instant"
if ! cmp -s "$capture.first" "$capture"; then
    echo "mock-modes: the same seed produced different output" >&2
    rm -f "$capture.first"
    exit 1
fi
rm -f "$capture.first"
echo "mock-modes: deterministic across runs"

# --- the firehose holds the frame budget -------------------------------------
#
# Frames are counted by their erase: every paint emits exactly one ED 0, and
# `[0J` appears in no other sequence the renderer writes. Counting the terminal
# escape rather than instrumenting the binary keeps this a black-box check.

started=$(date +%s)
run firehose "--mock-fault firehose"
elapsed=$(( $(date +%s) - started ))
[ "$elapsed" -lt 1 ] && elapsed=1

frames=$(grep -ao '\[0J' "$capture" | wc -l)
budget=$(( elapsed * 156 ))

printf 'mock-modes: firehose painted %s frames in %ss (budget %s)\n' \
    "$frames" "$elapsed" "$budget"
if [ "$frames" -gt "$budget" ]; then
    echo "mock-modes: the firehose outran the frame budget" >&2
    exit 1
fi

echo "mock-modes: every fault mode behaves"
```

`156` is 125 frames a second plus a quarter, matching Task 9's slack.
